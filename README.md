# Employee Attrition Analysis

This project is an end-to-end **HR Analytics and Employee Attrition Analysis** project designed to understand employee turnover, identify major attrition patterns, and generate actionable insights from employee data.

The project involves **data collection, data cleaning, preprocessing, exploratory data analysis (EDA), statistical analysis, KPI calculation, and data visualization**. Employee data is analyzed across different dimensions such as **department, job role, tenure, employee status, gender, age, and other workforce-related factors** to identify trends and patterns associated with employee attrition.

Multiple analytical and visualization tools are used throughout the project. **Python** is used for data cleaning, preprocessing, EDA, and visualization using Pandas, NumPy, Matplotlib, and Seaborn. **R** is used for statistical analysis and data visualization using packages such as dplyr and ggplot2. **Excel** is used for data preparation, calculations, Pivot Tables, and HR reporting, while **Power BI and Tableau** are used to create interactive dashboards and visual reports.

The final analysis provides a clear view of **overall attrition, department-wise attrition, monthly separation trends, tenure-wise attrition, active versus separated employees, and key workforce KPIs**. These insights can help HR teams identify areas with higher employee turnover and support better workforce planning and data-driven decision-making.

### Tools & Technologies

* Python – Pandas, NumPy, Matplotlib, Seaborn
* R – dplyr, ggplot2
* Microsoft Excel – Pivot Tables, Charts, Formulas
* Power BI – Data Modeling, DAX, Interactive Dashboards
